# Archivo INFOINVE 2025

Carpeta preparada para publicación en GitHub y uso desde el sitio DNPRI-IED.

- Documentos publicados: **82**
- Nomenclatura: `infoinve-pais-AAAA-MM.ext`
- `index.json`: índice para consumo automático desde el sitio web.
- `index.csv`: índice de control/consulta.

## Criterios de limpieza

Se excluyeron archivos temporales de Word, documentos ajenos a INFOINVE, documentos de otro año y versiones anteriores cuando existía una revisión posterior del mismo país/mes/formato. Los originales no fueron modificados.

## Archivos excluidos o reemplazados

- `Informe CFP Board.docx` — no corresponde a INFOINVE.
- `~$FOINVE Azerbaiyán marzo 2025.docx` — archivo temporal de Word.
- `INFOINVE Estados Unidos diciembre de 2024.docx` — corresponde al año 2024.
- `INFOINVE Bulgaria febrero de 2024.docx` — corresponde al año 2024.
- `Australia - INFOINVE febrero de 2025.docx` — no se pudo identificar el país.
